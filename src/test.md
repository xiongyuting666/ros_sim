# 测试用例文档
## 测试对象
ros_sim 简易ROS发布订阅模拟器

## 测试环境
- 操作系统：Windows
- 编译器：MinGW-w64 g++，C++11
- 运行方式：CMD

## 测试说明
预期结果：程序捕获异常，输出ERROR日志，程序不崩溃；正常流程打印INFO日志。

| 编号 | 测试类型 | 测试内容 | 预期结果 | 实际结果 |
| ---- | ---- | ---- | ---- | ---- |
| 1 | 正常功能 | 创建发布者、订阅者，绑定同一个话题，发布消息 | 订阅者成功收到消息，控制台输出INFO发布、接收日志，log.txt同步记录 |  |
| 2 | 正常功能 | 同一话题，1个发布者、多个订阅者，发布一条消息 | 所有订阅者都收到该消息，日志正常打印 |  |
| 3 | 异常测试 | 注册节点，节点名称为空 | 抛出NodeException，输出ERROR日志，程序继续运行 |  |
| 4 | 异常测试 | 注册两个同名节点 | 抛出NodeException，输出ERROR日志，程序继续运行 |  |
| 5 | 异常测试 | 话题名称为空，创建发布者/订阅者 | 抛出TopicException，输出ERROR日志，程序继续运行 |  |
| 6 | 异常测试 | 向没有订阅者、不存在的话题发布消息 | 抛出TopicException，输出ERROR日志，程序继续运行 |  |
| 7 | 异常测试 | 发布内容为空的消息 | 抛出MessageException，输出ERROR日志，程序继续运行 |  |
| 8 | 日志测试 | 正常运行、触发警告、触发错误 | INFO/WARN/ERROR分级输出，全部内容写入log.txt |  |
| 9 | 扩展功能 | 使用SensorMessage（温度、湿度、时间戳）发布 | 消息携带温度、湿度、时间戳，订阅端正常解析打印 |  |

## 测试总结
本次测试覆盖基础通信功能、多订阅广播、三类异常场景、日志持久化、扩展传感器消息。
所有异常场景均可被捕获，不会造成程序直接崩溃，符合设计要求。
